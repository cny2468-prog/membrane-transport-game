# 막 너머로

세포막을 통한 물질 이동을 익히는 3단계 웹게임입니다. 별도 설치 없이 `index.html`을 열면 바로 실행됩니다.

- 1단계(65초): 단순 확산, 촉진 확산
- 2단계(70초): 세포내 유입, 세포외 유출, 산소의 단순 확산
- 3단계(75초): 나트륨-칼륨 펌프와 ATP, 단순 확산, 촉진 확산

카드를 막의 빈칸으로 끌어다 놓거나, 카드를 누른 뒤 빈칸을 눌러 배치합니다. 장치마다 작동 횟수를 배분해야 하며 사용할 수 있는 전체 횟수는 제한됩니다. `막 작동시키기`를 누르면 각 물질이 세포막을 직접 통과하고 분포가 달라지는 모습을 확인할 수 있습니다. 농도 차이와 미션 문구는 새로 도전할 때마다 달라집니다.

세포막은 친수성 머리와 소수성 꼬리가 마주 보는 인지질 이중층으로 표시됩니다. 각 물질은 세포 안팎에서 계속 움직이며 산소, 포도당, 단백질, 이온은 서로 다른 모양으로 구분됩니다. 수송 횟수를 잘못 배분하면 수송 전 상태로 자동 복원되어 시간 안에 바로 다시 시도할 수 있습니다.

인지질은 머리 1개와 꼬리 2개를 가진 분자 108개로 직접 그려 두 층으로 배열했습니다. 이동 장치도 통로, 운반체, 펌프, 소낭의 구조 그림으로 표시됩니다. 물질은 한 개씩 해당 경로를 지나며, 소낭 수송에서는 소낭 형성·막 접근·막 융합·방출 과정이 차례로 재생됩니다.

막의 장치 자리는 모두 물음표로 표시됩니다. 장치의 위치나 배치 순서는 정답 판정에 영향을 주지 않으며 필요한 장치 조합과 작동 횟수만 확인합니다. 1단계에서는 장치 2개, 2단계와 3단계에서는 장치 3개를 사용합니다. 단순 확산은 빠르게, 운반체에 결합해야 하는 촉진 확산은 더 느리게 재생됩니다. 2단계의 세포내 유입·세포외 유출과 3단계의 나트륨-칼륨 펌프는 이동 장치 목록의 별 모양 ATP 카드를 필요한 장치 위로 직접 끌어다 놓아야 작동합니다. 클릭 후 장치를 누르는 방식도 지원합니다. ATP가 장치로 이동해 ADP와 Pi로 바뀌는 과정도 재생됩니다.

각 단계는 100점 만점이며 총점은 300점입니다. 성공 조건 달성도가 80점, 달성도에 비례한 남은 시간 보너스가 20점으로 계산됩니다. 조건을 모두 달성하지 못하거나 시간이 끝나도 힌트를 확인하고 다음 단계로 이동할 수 있으며, 같은 단계를 다시 도전해 더 높은 점수로 갱신할 수도 있습니다. 세 단계를 마쳐 250점을 넘으면 결과 화면에 생명과학 라운지 공유 안내가 표시됩니다.
